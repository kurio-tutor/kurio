# Vulnerability Disclosure Policy

This document explains how to report security vulnerabilities affecting Kurio.

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, email [help@support.kuriohop.com](mailto:help@support.kuriohop.com) with the subject
"Kurio security report" and include:

- The affected feature or URL.
- A description of the vulnerability and its potential impact.
- Steps to reproduce, with screenshots or a minimal example if helpful.

Do not include passwords or other people's personal information in your
report. Please keep vulnerability details private while we investigate and work
on a fix.

Thank you for helping keep Kurio and its learners safe.
